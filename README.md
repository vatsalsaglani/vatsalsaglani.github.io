# vatsalsaglani.github.io

Static mirror of [vatsalsaglani.pages.dev](https://vatsalsaglani.pages.dev), served by GitHub Pages from the root of this repository.

Do not edit the HTML here by hand. The source lives in
[vatsalsaglani/vatsalsaglanidev](https://github.com/vatsalsaglani/vatsalsaglanidev); this repo is regenerated with:

```bash
# from a checkout of vatsalsaglanidev, with this repo checked out as a sibling directory
npm run publish:gh
cd ../vatsalsaglani.github.io && git add -A && git commit -m "Publish site" && git push
```

`.nojekyll` is present so GitHub Pages serves the `_next/` directory as-is.
